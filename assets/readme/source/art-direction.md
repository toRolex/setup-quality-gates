# Art direction — setup-quality-gates README

Design source for the repository homepage visual system. Generated by
`beautify-github-readme`. Keep this file when editing the assets; the SVGs are
hand-authored against the frozen values below.

## Project story

```text
Project category:  Claude Code skill — commit-time quality-gate installer
Main user:         Claude Code users and repo maintainers who want a lint →
                   format → typecheck gate enforced before every commit
Main action:       run setup.sh once to install the gate into a target project
Best proof:        real terminal output — the post-install self-verify
                   (green OK) versus the gate blocking a dirty commit (red
                   GATE FAILED at python:lint)
Native visual:     terminal output, the lint→format→typecheck step chain, the
                   PreToolUse hook wiring, QUALITY_GATE_STACK, exit 2/0
Visual theme:      gate + terminal — monochrome technical with a gate-green
                   signal
```

## Visual system (frozen)

```text
Palette:
  bg        #0B0E11  deep carbon — terminal / gate backdrop
  surface   #141A1F  panel
  fg        #E6E8EB  warm white
  muted     #8B949E  neutral gray
  accent    #3FB950  gate green — checks pass / gate is green
  fail      #F85149  block red — ONLY inside GATE FAILED proof content,
                     never a theme color

Typography:
  display    system sans, 800 weight          — repository name / hero title
  section    system sans, 600 weight          — labels, section headers
  code/meta  ui-monospace                      — terminal, stacks, metadata
  sizes      hero title 60+, section 40+, body 22+, supporting 18+

Shape:
  radius    10   (cards, terminal window)
  stroke    1
  spacing   8    (grid unit)

Motif:
  The step-chain rail — three nodes (lint · format · typecheck) threaded on a
  horizontal track, each node carrying a passed check. It is the project's
  core mechanism (step chain) used as a gate cue. Repeat it lightly in the
  hero, section headers, and the mechanism diagram — never as wallpaper.

Composition:
  compact technical — strict grid, thin rules, mono metadata, one signal color.
```

## Hero composition (frozen)

- Canvas `1200 × 400`, split ~56% title / 44% proof.
- Left: category tag, repository name, plain-language value, step-chain rail,
  small metadata row (skill · stack(s) · license).
- Right: one terminal window showing the self-verify proof — the gate is green
  for `python`. Terminal chrome: traffic dots, mono output, green status dot.
- Own background so it reads on GitHub light and dark.
